# Student Focus Tools 🎓

A collection of tools designed to help students stay focused and organized.

## Tools Included

### 1. Student To-Do List ✅
A beautiful, glassmorphism-styled to-do list to keep track of your assignments and tasks.
- **Features**: Add, delete, and mark tasks as complete.
- **Persistence**: Tasks are saved automatically so you don't lose them.
- **Location**: `index.html` (Root)

### 2. Focus Watcher 📺
A distraction-free YouTube video player.
- **Features**: Watch educational videos without sidebar recommendations or comments.
- **Custom Controls**: Play/Pause, Speed (0.5x - 2x), Volume, and Fullscreen.
- **Location**: `focus-watcher/index.html`

## How to Use Locally
1.  Open the folder in your file explorer.
2.  Double-click `index.html` to open the To-Do List.
3.  Navigate to the `focus-watcher` folder and open `index.html` to use the Video Player.

## Hosting on GitHub Pages
Since this is a static website (HTML/CSS/JS), it can be hosted for free on GitHub Pages.

1.  Create a new repository on [GitHub.com](https://github.com/new).
2.  Upload all files from this folder to the repository.
3.  Go to **Settings** > **Pages**.
4.  Select the `main` branch and click **Save**.
5.  Your site will be live at `arduinoclassroom.github.io/Focus-Watcher`.
